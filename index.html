FAQ

常见问题解答

01 · 这个页面是否依赖第三方动画库？
不依赖任何 JS 动画库，所有效果均由原生 CSS 动画 / 过渡以及不超过 600 行的原生 JavaScript 实现，唯一的外部资源是字体与图标库。
02 · 粒子背景会不会影响页面性能？
粒子数量会根据屏幕宽度自动调整，并使用 requestAnimationFrame 进行帧同步渲染，同时在用户切换标签页时自动暂停，最大程度降低性能开销。
03 · 是否适配移动端与触屏设备？
所有布局均使用响应式网格与弹性盒模型，自定义鼠标光标在触屏设备上会自动隐藏，3D 倾斜效果在触屏上会优雅降级为静态卡片。
04 · 如何自定义配色与主题？
所有颜色、阴影、圆角与缓动函数均通过 :root 中的 CSS 自定义属性集中管理，只需修改对应变量即可一键切换整站视觉风格。
